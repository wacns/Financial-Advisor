## What's Changed

- Add separate local, ChatGPT-subscription foundation, hosted prepaid and bring-your-own-key assistant choices.
- Add session-only OpenAI API and Vercel AI Gateway keys with explicit provider-charge consent; exclude credentials from prompts, financial data and backups.
- Add a private prepaid-credit ledger with trusted grants, atomic request reservations, duplicate-request protection, usage metadata and idempotent settlement/refunds. Purchases and hosted pricing remain disabled until configured.
- Add approval-gated Continue with ChatGPT sign-in and explicit identity-linking foundations using Supabase custom OIDC and existing web/native PKCE callbacks. Subscription inference still needs the approved connection contract.
- Reset charge acceptance when provider/model/key or the hosted quote changes; never switch funding options automatically.
- Use version tags as release display names, such as v1.7.1, including notes-only title corrections. Preserve signing and prerelease status.
- Document the uploaded Budget Tracker feature comparison with current capabilities, gaps, alternative designs and recommended implementation order.

## Installers

APK/AAB, unsigned IPA, EXE, DMG/ZIP and AppImage/DEB are version 1.7.1. Public downloads contain installers and metadata; application source remains private.

## Known limitations

- ChatGPT identity sign-in is disabled until OpenAI approval and Supabase provider setup are verified. ChatGPT subscription inference is a separate pending integration, not an active billing fallback.
- Hosted AI requires the owner's Gateway key/model and a versioned per-question credit price. No pricing, payment provider or credit purchase flow has been chosen. No real credits or paid provider requests were issued during implementation tests.
- BYOK is session-only; provider availability, model support and API billing depend on each user's own account. Failed provider calls may still be charged by the provider.
- Credit settlement interrupted by a function/database outage may need administrative reconciliation. Recent request status is available; payment webhooks and automated abandoned-reservation recovery are not implemented.
- The budget comparison recommends future drafts, formulas, PDF reports and scoped sharing; those recommendations are not implemented by this release.
- Signing and physical-device limitations remain: IPA requires signing before installation; desktop builds are unsigned, and native installation, notifications, microphone/Shortcuts and update delivery require device testing.
